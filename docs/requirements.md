Requirements Specification

Project: Portable Guitar Amplifier
Revision: 0.1
Status: Draft

1. Project Overview

A compact, portable, rechargeable guitar amplifier using a custom-designed PCB and an integrated loudspeaker.

2. Functional Requirements 

REQ-001 The product should be of a small dimension so it can be easily portable
REQ-002 The product should have a integrated loudspeaker.
REQ-003 The product should aim for 1 W RMS audio output power.
REQ-004 The product should have a loudspeaker aproximatley of 3 inches.
REQ-005 The product should operate on a rechargable battery.

3. Electrical  and Power Requirements 

REQ-006 Battery operating time - At least 4 hours under defined typical-use conditions
REQ-007 Charging method - USB-C
REQ-008 Guitar input connector - 6.35 mm TS mono jack
REQ-009 Maximum acceptable distortion

4. User Interface Requirements

REQ-010 Volume control - User-adjustable
REQ-011 Tone Control - User-adjustable
REQ-012 Distortion Control - User-adjustable

5. Mechanical Requirments

REQ-013 Dimensions - (W x D x H): 110 x 60 x 140 mm
REQ-014 Weight - Weight: 0.34 kg
REQ-015 Portability Required

6. Verification

Each requirement shall eventually have a defined verification method, such as calculation, simulation, inspection or physical measurement.
